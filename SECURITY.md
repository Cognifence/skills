# Security policy

Email **security@cognifence.ai** to report a security vulnerability in these skills, such as a
step that could leak a Cognifence key or run commands the user did not intend.

Include the skill and commit you used, the coding agent that ran it, what an attacker can do,
and steps that reproduce it. Do not include API keys, MCP tokens, Connect keys, or other
credentials; if one was exposed, revoke it on the platform and say so in the report. We will
confirm that we received the report and keep you informed while we fix it.
