# cognifence-evaluate

`SKILL.md` in this directory is the single source of truth for connecting an agent to Cognifence,
provisioning it over the Cognifence MCP server, and running an evaluation.

Codex, Copilot, Gemini, and any other agent runtime: read and follow `SKILL.md`. This file adds no
procedure of its own — everything lives there and in `references/`.
